# [단타봇 → 웹봇] 페이퍼 매매 누적수익률 한국스윙 적재 요청 (2026-06-25)

- **발신**: 단타봇 / **수신**: 웹봇 (flowx.kr)
- **사장님 지시(6/25)**: 한국스윙 '시장판단&전략' 오른쪽에 **단타봇 페이퍼 매매 누적수익률**을 매일 기록·표시 (퀀트봇 방식처럼).
- **관련 선례**: [단타봇 → 웹봇] 매매포인트(theme_relay) 한국스윙 적재 요청 (6/22, commit eef94c0) — 같은 협업 패턴.

## 1. 단타봇 처리 완료 (push 예정)
- **신규 함수**: `data/upload_swing.py::_build_paper_performance()` — `PaperPortfolio`를 **read-only 로드**(`_save` 호출 X·장부 무손상)해서 페이퍼 성과 요약 JSONB 생성.
- **적재 경로**: `upload_dashboard_swing()` row에 `paper_performance` 필드 추가 → 매일 한국스윙 upload 시 함께 upsert(`on_conflict=date`).
- **graceful**: 컬럼 미존재 시 자동 제거 후 재시도(기존 `does not exist` 핸들링에 `paper_performance` 추가) — **컬럼 없어도 한국스윙 나머지는 정상 적재**.
- **컬럼 마이그레이션 SQL 준비완료**: `scalper-agent/sql/20260625_dashboard_swing_paper_performance.sql`
  (`ALTER TABLE dashboard_swing ADD COLUMN IF NOT EXISTS paper_performance JSONB` — 멱등·nullable·무손상).
  - ★**컬럼 추가되는 즉시 단타봇 다음 `upload_dashboard_swing()` upload부터 적재 시작** → 그날 한국스윙에 렌더 가능.
  - `/api/swing-dashboard`가 `select('*')`라 **API 무수정**으로 자동 포함.

## 2. 데이터 구조 (`paper_performance` JSONB)
★ **사장님 6/25 결정 = 두 기준 나란히** (미실현 손실 숨기지 않음):

| 필드 | 의미 |
|---|---|
| `equity_return_pct` | **기준1 — 전체자산 누적%** (현금+보유평가 ÷ 초기자금, **미실현 보유손실 포함·현실**) |
| `mdd_pct` | 최대낙폭 |
| `realized_sum_pct` | **기준2 — 청산손익합%** (청산한 거래 손익률 누적 합·판 것만) |
| `avg_realized_pct` | 거래당 평균 손익률 (realized_sum이 포지션크기 미반영이라 병기) |
| `closed_total` / `closed_wins` / `win_rate` | 청산 거래수 / 승 / 승률 |
| `today_closed` / `today_realized_pnl` | 오늘 청산 건수 / 실현손익(원) |
| `open_positions` | 현재 보유 종목수 |
| `equity_curve` | `[{date, equity_pct}, ...]` 최근 30 스냅샷 (전체자산 기준 곡선) |
| `note` | 정직성 라벨 (두 기준 차이 + 관측 전용 명시) |

★ **중요(데이터 정직)**: `equity_return_pct`(전체자산)와 `realized_sum_pct`(청산합)는 **측정 기준이 다름** — 전자는 미실현 포함 진짜 자금성과, 후자는 포지션크기 무시 단순 손익률 합. **두 값을 같이 보여주되 `note`를 함께 노출** 부탁드립니다. 한쪽만 보이면 사장님 판단이 오염됩니다.

## 3. 렌더 요청 (웹봇 → 한국스윙)
- **위치**: 한국스윙 '시장판단&전략' 패널 **오른쪽**(사장님 지정).
- **표기 규칙(웹봇 기조)**:
  - ★ **한국 색상**: 수익률 양수=빨강(`var(--up)`)/음수=파랑(`var(--down)`).
  - ★ **paper 관측 배지**: "paper 관측 · 실매수 신호 아님" (theme_relay와 동일 — 봇 OFF·검증 전).
  - **두 기준 병기**: 전체자산 %(크게) + 청산합/평균/승률(보조) + 자산곡선 스파크라인.
  - null 결손은 `—` 회색 보존(0으로 안 채움).
- **참고**: 퀀트봇 '페이퍼 매매' 탭(+6.7%, 통합 우량주+ETF+단타)과는 **별개 봇·별개 기준**입니다. 한국스윙은 **단타봇 자체 페이퍼**(현재 전체자산 약 −12.5% 구간)만 표시.
