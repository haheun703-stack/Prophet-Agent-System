## 3. KRX Data Marketplace 분석

### 상품: "주식 투자자별 거래실적"
- 가격: KOSPI 50,000원/월 + KOSDAQ 50,000원/월 = **월 10만원 / 연 120만원**
- 산출주기: 1분/10분/**1일**
- 데이터 형태: CSV
- **데이터 전달 방식: 이메일, 웹 다운로드** ← 치명적 문제

### 🚨 왜 부적합한가
- **수동 CSV 배포 방식** — API 호출 불가
- 매일 이메일/웹에서 CSV를 사람이 다운로드해야 함
- 실시간/자동 파이프라인에 통합 불가
- 연간 구독형도 전달 방식 동일 (확인 안 했지만 과거 경험상 동일)

### 💡 유일한 가치
백테스트용 과거 데이터 대량 구매 시만 의미 있음 (T3 감지기 학습용).
실시간 자동매매에는 부적합.

## 4. KIS OpenAPI 실제 한계

### 이미 연동 중인 TR
`flow_collector.py`가 이미 **2026-03-04**부터 KIS API로 전환 완료.

#### `FHKST01010900` - 종목별 투자자별 매매동향 (30일치)
- 엔드포인트: `/uapi/domestic-stock/v1/quotations/inquire-investor`
- 제공 필드:
  - `frgn_ntby_qty/tr_pbmn` → 외국인 순매수 수량/금액
  - `orgn_ntby_qty/tr_pbmn` → **기관계 (통합)**
  - `prsn_ntby_qty/tr_pbmn` → 개인
  - 기타법인 = **-(외+기+개) 역산**으로 계산

**→ 종목별 4주체만 제공** (외/기관계/개/기타법인)

#### `FHPTJ04040000` - 시장별 투자자 매매동향 (KIS 공식 예제 존재)
- 엔드포인트: `/uapi/domestic-stock/v1/quotations/inquire-investor-daily-by-market`
- **시장 전체** 9주체 세부 가능 (KOSPI/KOSDAQ)
- 현재 미연동 (KIS 공식 SDK `KISOpenAPI_260320/api/kis_api.py`에 샘플 있음)

### KIS의 치명적 한계
**종목별로는 기관 세부 분해 불가.**
금융투자/보험/투신/사모/은행/연기금/기타금융 구분은 종목별로 KIS OpenAPI가 안 줌.
**시장 전체로만 가능.**
