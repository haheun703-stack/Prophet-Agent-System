## 4. 퐝가님 질문: "조용한 매집 → 상승 → 급등" 패턴

### 실측 결과

**존재하지만 전체의 ~5%에 불과**

```
전형적 패턴 (외인 20일 100억+ 매집 + 직전주 횡보 + 7%+ 급등)
= 34건 / 6,715건 = 0.5%
```

### 현실의 패턴 비중

| 패턴 | 비중 | 설명 |
|:---:|:---:|:---|
| **갑자기 폭격** | ~78% | 사전 매집 없이 당일 대량 매수 진입 |
| **1~3일 단타** | ~12% | 짧은 매수 후 급등/급락 |
| **조용한 매집→급등** | ~5% | 퐝가님이 보신 패턴 (희귀) |
| **대량 매집→던지기** | ~5% | 8-10일 매수 후 오히려 하락 |

### 왜 "매집" 패턴이 보이는가?

우리가 **급등한 종목을 사후에 보면** 매집처럼 보이는 이유:
1. 급등 전 가격 자체가 이미 +6.8% 상승 중 (모멘텀)
2. 그 상승을 외국인 매집으로 착각하기 쉬움
3. 실제로는 개인/테마/뉴스가 선행하고, 외국인은 **나중에 합류하거나 안 함**

**진짜 위험한 패턴**: 8~10일 연속매수 후 종료 → 후 5일 -0.17%, 승률 45%
→ "매집 완료 = 지금이 고점"일 수 있음

### 패턴 4: 분할매수 = TWAP 알고리즘 증거

```
3일 연속매수 (41,513건):
  Day1: 32.7% | Day2: 33.0% | Day3: 34.4%  → 거의 균등
```
