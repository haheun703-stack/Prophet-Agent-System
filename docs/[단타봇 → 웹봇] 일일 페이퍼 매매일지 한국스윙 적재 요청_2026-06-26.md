# [단타봇 → 웹봇] 한국스윙 '일일 페이퍼 매매일지' 패널 추가 요청 (2026-06-26)

- **발신**: 단타봇 / **수신**: 웹봇 (flowx.kr)
- **관련**: [단타봇 → 웹봇] 페이퍼 매매 누적수익률 한국스윙 적재 요청 (6/25) — 같은 `paper_performance` 컬럼 재사용.

## ■ 무엇
한국스윙(`dashboard_swing`) '시장판단&전략' 옆 페이퍼 패널 **하단**에, 단타봇 페이퍼 **당일 매매일지(매수/매도 체결 내역)**를 매일 표시. (6/25 요청한 누적수익률 패널 바로 아래)

## ■ 데이터 경로 (API 무수정)
`dashboard_swing.paper_performance` JSONB **안에 `today_trades` 배열**을 단타봇이 매일 적재(구현 완료·배포).
- `paper_performance` 컬럼 미생성 시: `ALTER TABLE dashboard_swing ADD COLUMN IF NOT EXISTS paper_performance JSONB;`
- `/api/swing-dashboard`가 `select('*')`라 컬럼 추가만 하면 자동 포함.

## ■ `today_trades` 구조 (배열 — 그날 체결만)
```json
[
  {
    "side": "SELL",              // "BUY" 또는 "SELL"
    "code": "001740",
    "name": "SK네트웍스",
    "entry": 9690,               // 진입가
    "exit": 10789,               // 청산가 (BUY는 null)
    "shares": 139,
    "pnl_pct": 11.33,            // SELL만 (BUY는 null)
    "pnl_krw": 152761,           // SELL만 (BUY는 null)
    "reason": "TARGET",          // 청산사유 (BUY는 "")
    "hold_days": 2,              // SELL만 (BUY는 null)
    "source": "daytrading_pick"  // 매매 출처
  }
]
```

## ■ 요약 필드 (`paper_performance`에 이미 있음 — 일지 헤더용)
`date`, `today_closed`(오늘 청산수), `today_realized_pnl`(원), `equity_return_pct`(누적·전체자산·미실현포함), `realized_sum_pct`(청산합), `open_positions`

## ■ reason 한글 라벨 매핑 (단타봇 페이퍼 실제 값)
`TARGET`=목표익절 / `STOP`=손절 / `TRAILING_STOP`=트레일링(고점-3%) / `TIME_STOP`=보유만기 / `NXT_MORNING_SELL`=NXT익일시가 / `TOP_MORNING_SELL`=TOP익일시가 / `limit_up`=상한가분할 / (BUY는 reason "" = 신규진입)

## ■ source 라벨 매핑
`daytrading_pick`=단타TOP픽 / `nxt`=NXT야간 / `limit_up`=상한가 / `morning`=모닝(레거시)

## ■ 렌더 요청 (스크린샷 '매매 내역' 형식 참고)
- 제목: "📒 일일 페이퍼 매매일지 (YYYY-MM-DD)" + 배지 "paper 관측 · 실매수 아님"
- 요약줄: 매수 N · 매도 M · 오늘 실현 ±원 · 누적(전체자산) ±%
- 테이블(행=거래):

| 구분 | 종목 | 진입→청산 | 수량 | 손익률 | 전략 | 보유 |
|---|---|---|---|---|---|---|
| SELL | SK네트웍스 | 9,690→10,789 | 139 | +11.33% | 목표익절 | 2일 |
| BUY | 삼성바이오 | 1,387,386 | 5 | — | 신규진입 | — |

- ★ 한국 색상: 손익 양수=빨강(`var(--up)`) / 음수=파랑(`var(--down)`)
- BUY는 손익/보유 칸 "—" 회색
- 거래 0건인 날: "오늘 매매 없음" 회색 1줄
- null 결손은 "—" 보존(0으로 안 채움)

## ■ 정직성 (사장님 룰)
`equity_return_pct`(전체자산·미실현 포함)가 진짜 성과 = 현재 약 −12% 구간. 일지는 그날 '체결'만 기록(청산합/+표시가 좋아 보여도 미실현 손실 별개). 봇 OFF · paper 관측 전용 · 실매수 신호 아님.

## ■ 회신 요청
- 렌더 위치/형식 이견 있으면 회신.
- 단타봇 `today_trades` 적재 시작분(첫 1건) 확인되면 알림 → 실측 렌더 확인.
