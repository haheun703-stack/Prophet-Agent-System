### 2-2. morning_recommendation step5 수급 보너스

**파일**: `data/morning_recommendation.py` (`_step5_cross_validate`)
**현재**: relay/premove/tech/news/macd/nationality/bargain/tv/rotation/trix
**변경**: + `bomb_watchlist` 파라미터 추가

```python
# _step5_cross_validate에 추가할 점수 요소:

# A) SECOND_BOMB/EARLY(2차) 보너스
if code in bomb_watchlist:
    bomb_info = bomb_watchlist[code]
    bomb_bonus = bomb_info.get("bomb_adj", 0)  # +15 or +12
    total_score += bomb_bonus
    sources.append(f"수급폭탄({bomb_info['signal']})")

# B) 역추세 보너스: 전일 하락(-2%+) + 외인 매수 = 저가 매집 패턴
if prev_change <= -2.0 and foreign_today > 0:
    contrarian_bonus = 5  # 외인 역추세 매수 패턴
    total_score += contrarian_bonus
    sources.append("역추세매집")

# C) 요일 가중치 (화~수 = 외인/기관 피크)
dow = datetime.now().weekday()  # 0=월
if dow in (1, 2):  # 화, 수
    total_score += 3
    sources.append("화수부스트")
elif dow == 0:  # 월요일
    # 개인 주도 종목 감점 (개인매수 비율 높으면)
    if individual_ratio > 0.6:
        total_score -= 5
        warnings.append("월요일 개인쏠림 주의")

# D) 개인 매도폭발 + 외인 매수 = 물량 받기 패턴 (71% 반대매매)
if foreign_today > 0 and individual_today < 0:
    mirror_ratio = abs(individual_today) / max(abs(foreign_today), 1)
    if mirror_ratio >= 0.5:  # 개인이 외인의 50%+ 물량 던짐
        total_score += 3
        sources.append("거울매매")
```

### 2-3. auto_trader 트랙B 진입 조건

**파일**: `bot/auto_trader.py` (진입감시 루프)
**현재**: 모든 종목 동일 6조건
**변경**: `watch.get("entry_rule") == "bomb_d1"` 이면 트랙B 3조건

```python
# 트랙B 진입 조건 (기존 6조건 대체)
if watch.get("entry_rule") == "bomb_d1":
    conditions_met = 0

    # B-1) 갭 0% 이상 (하락갭 제외)
    if gap_pct >= 0:
        conditions_met += 1
        conditions_detail.append(f"갭{gap_pct:+.1f}%")

    # B-2) 체결강도 100+ (매수 우위)
    if strength >= 100:
        conditions_met += 1
        conditions_detail.append(f"체결{strength:.0f}")

    # B-3) 기관 합류 확인 (D+1 기관 매수 = 54% 합류 패턴)
    # 장중에는 체결강도로 대체 (기관 데이터는 장마감 후)
    # 체결강도 120+ = 기관 합류 가능성 높음
    if strength >= 120:
        conditions_met += 1
        conditions_detail.append("기관합류추정")
    elif gap_pct >= 3.0:
        # 갭 3%+ = 모멘텀 확인 (통계: 가장 수익 좋은 그룹)
        conditions_met += 1
        conditions_detail.append(f"모멘텀갭{gap_pct:+.1f}%")

    entry_threshold = 2  # 3조건 중 2개
```

### 2-4. position_guardian 트랙B 청산 규칙

**파일**: `bot/position_guardian.py` 또는 `bot/auto_trader.py` (매도 로직)
**현재**: SL -3.5%, 트레일링 -2%, 최대 5일
**변경**: 트랙B 태그 종목은 전용 규칙

```python
# 트랙B 청산 규칙
if position.get("track") == "B":
    # TP +3% → 즉시 매도
    if current_ret >= 3.0:
        return SELL, f"트랙B TP도달 {current_ret:+.1f}%"

    # SL -2% → 즉시 손절
    if current_ret <= -2.0:
        return SELL, f"트랙B SL도달 {current_ret:+.1f}%"

    # 14:30 강제 청산 (당일매매 원칙)
    if now.hour == 14 and now.minute >= 30:
        return SELL, f"트랙B 14:30 강제청산 {current_ret:+.1f}%"

    # D+2 이후 보유 금지 (1~3일 단타 원칙)
    if holding_days >= 2:
        return SELL, f"트랙B D+{holding_days} 강제청산"
```

### 2-5. TWAP 감지 태그 (보조)

**파일**: `tools/supply_pattern_detector.py`
**현재**: QUIET_ACCUM은 5일 합산만
**변경**: 일별 균등성 체크 추가

```python
# TWAP 감지: 3일+ 연속매수 AND 일별 편차 < 30%
if consec_days >= 3:
    daily_amounts = [foreign[i] for i in range(start, end)]
    avg = np.mean(daily_amounts)
    if avg > 0:
        max_dev = max(abs(d - avg) / avg for d in daily_amounts)
        if max_dev < 0.3:  # 30% 이내 편차 = TWAP
            tags.append("TWAP_DETECTED")
            note += f" (TWAP {consec_days}일 균등매수)"
```
