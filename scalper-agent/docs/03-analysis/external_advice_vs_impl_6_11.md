## E2 3-way 설계 (Fable 5 제안 + 단타봇 보강)

**Fable 5 핵심 통찰 (단타봇 인정)**: 5/21 사고와 E2는 "양날의 검"이 아니라 **다른 칼**이다.
- **무조건 N일 청산** → "안 가는 놈"도 "가는 놈"도 자름 → **5/21 사고의 원인**
- **조건부 E2** → "안 가는 놈"만 자름, "가는 놈"은 트레일링으로 → **사고와 충돌 안 함**
- 5/21 교훈 재해석: *"시간청산이 나쁘다"가 아니라 "무조건 시간청산이 나쁘다"*

**3-way 비교 (6/12 shadow)**:
- ① **무조건 3일 청산** — 현 REVERSAL 룰 (`auto_trader.py:4726`, `if code in reversal_codes: effective_max=min(.,3)`)
- ② **트레일링 끝까지** — 시간청산 없음 (asset_pool 현 동작, `auto_trader.py:4711` 보유일룰 차단)
- ③ **조건부 E2** — D+1 종가 +0.5R 미달 시만 3일 청산, 도달 시 트레일링 이관

**★ 단타봇 보강 1 — R 정의 정합 (필수)**: Fable 5의 1R = 1×ATR이나 우리는 ATR 미사용. 우리 시스템 번역 = **R = 손절폭 3% → +0.5R = +1.5%**. 즉 ③ = "**D+1 종가까지 +1.5% 미달 시 청산**". 이 번역 없이는 3-way가 우리 시스템에서 성립 안 함.

**★ 단타봇 보강 2 — +0.5R 일봉 측정 한계 (caveat)**: "+0.5R 도달" 판정을 일봉 종가로 하면 장중 휩쏘를 과소평가(5/31 메타교훈). forward 측정 시 분봉/실측 보정 필요.

**핵심 관측 = ② vs ③ 차이**: ③ > ② 면 "안 가는 포지션의 기회비용"이 실재 → E2 valuable. 차이 없으면 E2 기각, 트레일링-only 유지.
