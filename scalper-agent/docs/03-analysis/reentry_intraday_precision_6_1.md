# 라이브 숙제 #2 — 재진입 분봉정밀 교차검증 (6/1)

> 도구: `tools/reentry_intraday_precision_6_1.py` (셀프테스트 8/8, 게이트 8/8 무손상, 순수 read-only).
> 데이터: stock_data_daily(이벤트 검출) + data_store/1min(홀딩윈도 정밀 재현, ~6주 2026-02~03).

## 목적
#1(reentry_cost_sensitivity)은 **일봉 근사**: 트레일peak=일봉high, 손절=일봉low, 재진입=일봉close.
이건 장중 '순서'와 슬리피지를 못 본다. #2는 **같은 STOP_REENTER 규칙을 1분봉으로 정밀 재현** →
#1의 5.0배 헤드룸이 장중 현실에서도 견고한가.

## ★ 결과 (335 이벤트, 분봉보유 & 홀딩윈도 전체 커버) ★

| 방식 | RE세그 | RE_g% | ONCE_g% | vs ONCE 헤드룸 |
|---|---|---|---|---|
| 일봉근사 (= #1 재현) | 1.55 | 7.34 | 5.80 | **5.8x** |
| 분봉 장중재진입 (slip0) | 11.40 | 7.15 | 3.01 | **0.8x** |
| 분봉 EOD재진입 (slip0) | 1.99 | 3.23 | 3.01 | **0.5x** |
| 분봉 EOD재진입 (slip0.2% 실집행) | — | 2.71 | 2.81 | **-0.2x** |

## 결론 — #1의 paper-GO(비용차원)는 분봉정밀에서 붕괴

1. **헤드룸 5.8x → 0.5~0.8x 붕괴** (slip0에서도, 슬리피지 무관하게 해상도만으로).
2. **세그먼트 폭발(11.40)은 재진입 과공격 탓**: EOD(일봉처럼 종가 1회/일) 규율하면 1.99로 일봉(1.55) 수준 회복.
   → 재진입은 반드시 EOD/쿨다운으로 규율해야 (naive 장중 재진입 = 휩쏘 자살).
3. **그러나 EOD로 규율해도 헤드룸 0.5x로 붕괴.** 진짜 원인 = **장중 '손절'이 일봉보다 일찍·자주 터짐**:
   ONCE gross가 일봉 5.80% → 분봉 3.01%로 반토막, 재진입 엣지(RE−ONCE) 1.54%p → 0.22%p로 소멸.
4. **근본**: "고점 -3%"를 **분봉 고점**(매분 갱신)으로 재면 **일봉 고점**(하루 1회 갱신)보다 훨씬 타이트 →
   휩쏘·조기손절. 일봉 백테스트(5/31 전부 + #1)가 이 해상도 차이를 구조적으로 숨겨왔다.
