## 0. 한 줄 철학 (사장님)
> **"명분 있는 끼 종목을, 맥점에서 사서, -3%로 타이트하게 자르되 추세 살아있으면 재진입하고, 줄 때 먹는다."**

## 1. 3대 격언 + 7요소 (사장님 철학)
- **명분(名分)**: 왜 오르는가 — 재료/이유 없는 종목 안 산다 (종목선정 80%)
- **맥점(脈點)**: 살 자리 — 눌림/돌파/지지 변곡점에서만
- **줄먹**: 줄 때 먹어라 — 욕심 말고 확실히 익절
- **7요소 체크**: 재무·재료·수급·기술위치·**끼부림**·스케줄·시나리오 (끼부림 = 가장 단타스러운 = 수익원)

## 3. 4단 종목선정 (명분→끼→맥점→시나리오) — 현재 shadow 구현
> 설계: `docs/02-design/style_4stage_selection_5_31.md`. 구현: 브릭1~4 (5/31, shadow=선정 불변).

- **Stage0 명분게이트**: 44신호→7요소 버킷, {재료·수급·기술위치} 강≥2 → 통과. 약신호 더미 픽 사살. (`_aggregate_thesis_buckets`)
- **Stage1 끼부림**: `score_kki()` 6팩터 0~100 (변동성35·급등빈도25·회전15·연속10·종가10·거래량5) → EXPLOSIVE/HUNTABLE/MODERATE/SLUGGISH
- **Stage2 맥점**: 눌림 -3%(`SAJANG.ENTRY_MODE_DEFAULT`)·VWAP 3분할 (유지)
- **Stage3 시나리오**: TradeObject 선언(tp1/trail/invalidation/hold_plan, SAJANG 경유)
- ★ **현재 = shadow**: 끼·명분 계산·기록·로그만, **picks 안 바뀜**(cutoff `total_score>0` 그대로). 게이트 8/8 유지, 32 테스트 PASS.

## 4. 진입/청산/재진입 룰 (전부 SAJANG 단일진실)
> 설계: `docs/02-design/reentry_rule_5_31.md`. ★ 값은 전부 `data/sajang_rules.py` 경유(리터럴 금지).

- **진입**: 명분 있는 高끼 종목, 맥점(눌림/돌파)에서. 30% 현금 보유.
- **손절**: 고점-3% 트레일(`SAJANG.get_trailing_sl`) / 진입 -3% 안전망(`get_normal_sl`). **타이트 유지.**
- **재진입(설계완료·미구현)**: 손절 후 종가가 손절선 회복(reclaim) + 명분유효 + 끼≥MODERATE + 윈도우내 → **당일 종가, 최대 2회, 풀 비중** 재매수.
- **보유**: **D+3 단타 기본** + EXPLOSIVE 끼 winner만 추세 끝까지 RIDE(D+10 캡).
- **줄먹**: +10% 룰B 절반익절 / 상한가 +25%→+29% 절반 / 트레일링. (고정TP=0, 트레일링only)

## 5. 현재 상태 & 다음 단계 (순서 엄수)
```
[게이트 8/8 복구 ✅] → [매매철학 데이터검증 ✅] → [재진입 설계 ✅] → [4단 shadow 브릭1~4 ✅]
→ ★다음: 봇 가동(paper) → shadow 로그 관측(명분통과 분포·새픽vs옛픽 며칠) → 브릭5 flip(사장님 결정)
→ 끼 랭킹반영(asset_pool_loader) + HIGH_VOLATILITY -5 모순해소 → 재진입 구현
→ 라이브 숙제(분봉정밀·비용민감도·생존편향보정·6팩터끼) → paper 검증 → 사장님 승인 → live
```
- ★ **브릭5 flip(선정 변경)은 관측 데이터 + 사장님 결정 전 금지** — 관측 없이 flip = "검증 전 가동" 사고 재발.
