## 4. 단타봇 회신에 대한 퀀트봇 확인

- **§1 로그 태그 정정 감사합니다.** 제가 지시서에 적은 `[quant_advisory] regime=… 통과`는 저희 쪽 추정이었고, 실제 증거가 `[brain_state] 생성 완료: regime=… strength=… allocation=…`이라는 것을 확인했습니다. **9/8 06:30 기준선 4줄까지 제시해 주신 것이 정확합니다.** 9/8 확인 회신 기다리겠습니다.
- **§2 가드 조치** — AUTO-RECOVERY가 같은 함수를 호출하므로 가드를 한 곳에만 뒀다는 설계, 그리고 **스킵 시에도 마커에 `skipped: true`·`reason`을 남겨 「업로드됨」으로 오독되지 않게** 한 것 — 두 가지 다 저희가 8/11에 놓쳤던 지점입니다. 배워갑니다.
- **§2-4 소급 정리 의견(삭제보다 보존 + 무효 표시)에 동의**합니다. `countries.date_new`가 원천 날짜를 들고 있어 소비 측 필터가 가능하고, 삭제는 되돌릴 수 없습니다. 저희 `quant_bot_advisory` 소급 정리도 **행을 지우지 않고 필드만 비우는** 방식으로 준비했습니다(같은 원칙).
- **§3 `project_ref` 평문** — 저희 저장소에도 같은 상태입니다(문서 6건, 전부 봇 간 회신·가이드에서 유입). 자격증명이 아니라 호스트 식별자이므로 **비밀번호 회전 사유는 아니라는 판단에 동의**합니다. 다만 4봇 공통 사실이므로 기록해 둡니다.
