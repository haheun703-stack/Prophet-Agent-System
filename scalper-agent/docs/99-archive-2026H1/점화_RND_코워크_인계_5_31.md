## 0. TL;DR (한 줄)

점화 신호는 **통계 엣지 실재**(고점 도달 x1.6~2.3)하나, **기계적 일봉으론 수익 실현이 안 됨(breakeven)** — 진입·청산·필터 어떤 조합도. → **자동무기 아님(가드레일 확보)**. 진짜 엣지는 일봉이 못 보는 곳(분봉 + 수급·재료 명분)에 있고, 그건 **6/1 shadow 관측**이 검증 수단. 신호의 현실 값어치 = **워치리스트 생성기**.

## 2. 핵심 결론 3개 (정직)

1. **엣지는 실재한다** — 점화 후 고점 도달 확률이 아무 날의 1.6~2.3배. 생존편향 보정(전 유니버스). 큰 수익일수록 엣지↑.
2. **기계적 일봉으론 수익 실현 안 된다** — 진입(추격/맥점) × 청산(3/8/ATR) × 필터(끼/기술위치) **모든 조합 breakeven(~0%, 승률 37%)**, 수수료·세금 빼면 마이너스.
3. ★ **"고점 도달" ≠ "수익 실현"** ★ — 끼는 fwd_max(고점)에선 x2.13인데 실현수익은 안 올림. **고끼=고whipsaw**: 고점은 높이 가지만 그 path가 트레일 손절을 더 털어냄. 이게 2번의 근본 이유.

## 3. 일봉 백테스트의 원천적 한계 (왜 여기서 멈추나)

- **수급·재료 명분을 못 본다** — OHLCV에 없음. 4단의 핵심 명분(기관·외인 수급, 뉴스·테마)이 일봉 백테스트엔 부재 → 진짜 4단 검증 불가. (기술위치만 MA20 프록시로 됨, 효과 0)
- **일봉 path = whipsaw** — 분봉 진입/청산 타이밍을 못 본다. 사장님 수동 엣지(분봉·재량)는 일봉이 과소평가.
- **상폐종목 부재** — 유니버스 생존편향 잔존(이미 상장 유지 종목만).
- **수수료·세금 미반영** — breakeven이면 실질 마이너스.

→ 즉 **일봉 백테스트는 "기계적 자동화는 안 된다"까지만 증명 가능**. 진짜 엣지(분봉·수급·재료·재량)는 다른 수단 필요.

## 4. 역할 분담 (일봉 R&D vs 6/1 shadow) — 정합

| 수단 | 검증 가능 | 검증 불가 |
|---|---|---|
| 일봉 백테스트(오늘) | 기계적 자동화 가부(=불가, 가드레일) | 수급·재료 명분 / 분봉 타이밍 |
| **6/1 shadow 관측** | **실데이터 수급·재료 명분 + 끼 + forward 수익** | (장기 누적 필요) |

→ 오늘 R&D는 "자동화 금지" 가드레일을 박았고, **6/1 shadow가 일봉이 못 본 진짜 4단을 검증**한다. 둘이 충돌 아니라 보완.

## 5. 코워크 다음 할 일 (우선순위)

1. **[1순위] 6/1 shadow로 무게중심 이동** — 점화 신호를 6/1부터 **워치리스트 생성기**로 활용: 매일 점화 종목 산출 → recommendation 일일스냅샷에 점화태그 + 끼 + (실데이터)수급·재료 명분 + forward T1/T2/T3 수익 누적. ≥10거래일 후 "점화+수급+끼 통과 픽이 실제 forward 양수인가" 검증. ← 이게 일봉이 못 한 진짜 검증.
2. **[2순위, 데이터 있으면] 분봉 점화 검증** — 분봉 데이터 존재 확인(stock_data_minute 등). 있으면 점화 당일/익일 **intraday 진입·청산**으로 일봉 whipsaw 회피 시 양전환되나. 없으면 보류.
3. **[참고] 점화 신호 = 자동매매 X** — 5회 백테스트로 standalone 기계 자동화는 breakeven 확정. 자동 점화봇 깔지 말 것. 워치리스트 + 끼·명분·재량 결합으로만.
4. **[정밀화, 선택] 상폐종목 포함 데이터** 확보 시 엣지 재측정(생존편향 제거) → 1번 엣지 숫자의 진위 보강.

## 7. 정직 단서 (박사 책임)

- 오늘 단타봇 가설 2회 연속 기각당함(줄먹이 절반→exit 못구함 / 맥점이 결정조각→맥점도 breakeven / 끼필터가 살림→필터도 breakeven). **데이터가 감을 계속 교정 = 정상 과학.**
- breakeven은 "사장님 수동 단타가 안 된다"가 **절대 아님** — "단순 기계 일봉 버전이 자동 현금기계가 아니다"일 뿐.
- 엣지 숫자(x1.6~2.3)는 생존편향 부분 잔존 + 수수료 전. 실전 net은 더 낮음. 과신 금지.
