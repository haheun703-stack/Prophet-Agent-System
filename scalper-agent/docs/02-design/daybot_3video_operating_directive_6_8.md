# 단타봇 3개 영상 통합 운영 지시서 (2026-06-08)

> 목적: 사장님이 공유한 3개 단타 영상에서 실제 단타봇에 참고할 부분만 추려,
> 자동매매 코드 변경 전 `관찰 -> 리포트 -> paper/shadow -> live 승인` 순서로 적용할 수 있게 정리한다.
>
> 전제: 이 문서는 매매 철학/운영 지시서다. `SAJANG` 영구 룰, 30% 현금 보유, 트레일링 only,
> 봇 OFF/freeze, 4-Tier 검수 의무를 우선한다. 본 문서만으로 live 룰을 즉시 변경하지 않는다.
> 6/8~6/12 1차 paper 관측의 기준선은 건드리지 않는다. 본 문서의 라벨/코드 반영은 6/12 KEEP/DROP/TUNE 판정 이후에만 검토한다.

---

## 0. 핵심 결론

3개 영상의 공통 메시지는 하나다.

**단타봇은 지수 예측기가 아니라, 당일 돈이 몰리는 주도주를 찾아 D+1/D+2까지 추적하고, 힘이 꺾이면 추가매수 없이 빠르게 정리하는 실행 엔진이어야 한다.**

따라서 적용 우선순위는 아래 순서다.

1. **손절/추가매수 금지 Discipline Gate** - 계좌를 망가뜨리는 행동 차단
2. **주도주/상대강도 Leader Gate** - 지수보다 강한 종목만 후보화
3. **이벤트 테마 Calendar Gate** - 기대감 구간과 재료 노출 구간 분리
4. **D+1/D+2 운용 Rule** - 장대양봉/상한가 이후 며칠간 반복 관찰
5. **복기/학습 Loop** - 매일 장후 놓친 종목과 실패 종목 기록

## 1. 영상별 추출 원칙

### A. 이벤트 테마 영상 - 기대감은 이벤트 전에 끝난다

참조 사례: 젠슨황 방한 기대감, LG/현대차/로봇/AI 테마, 삼성전자 D+1 외부충격 눌림.

단타봇에 필요한 부분:

- 강한 뉴스가 나오면 `event_date`를 반드시 기록한다.
- 뉴스 직후 1~2거래일은 기대감 구간으로 적극 관찰한다.
- 3거래일차부터는 추격매수를 금지한다. 급락 반등은 자동매수 후보가 아니라 관찰/리포트 라벨로만 둔다.
- 이벤트 전일과 이벤트 당일은 신규 진입 금지 또는 매우 강한 경고 상태로 둔다.
- 실제 호재 발표/방문/계약일이 가까워질수록 차익실현 수요가 커진다고 본다.
- 주도 테마 급락이 지수를 끌고 내려갈 때, 별도 주도주가 외부 충격으로 눌린 경우만 `external_shock_pullback` 관찰 라벨로 분리한다.

단타봇 지시:

```text
Event Theme Gate

1. event_date가 있는 테마는 T+0/T+1/T+2를 기대감 관찰 구간으로 둔다.
2. T+3부터 chase_buy 금지. 급락 후 반등은 관찰 라벨로만 리포트하고 자동매수 금지.
3. event_date-1, event_date에는 신규 진입 금지 경고를 띄운다.
4. event_date 임박 보유분은 줄먹/부분익절/트레일 우선으로 본다.
5. 테마 대장 급락으로 지수가 밀릴 때, 별도 D+1 강세주가 동반 급락하면 외부충격 눌림 관찰 라벨로만 분리한다.
```

적용 금지:

- "테마가 강하다"만으로 무조건 매수
- 이벤트 당일 호재 확인 후 뒤늦게 추격
- 대장주가 꺾였는데 2등/3등주를 늦게 추격

---

### B. 주도주 영상 - 지수보다 돈이 몰리는 곳을 본다

참조 사례: 지수가 강해도 일부 종목만 상승, 비주도주는 하락. 삼성전자/하이닉스/삼성전기/로봇/LG/현대차 등 쏠림.

단타봇에 필요한 부분:

- 지수 상승률만 보고 매매하지 않는다.
- 상승장에서도 비주도주는 제외한다.
- 하락장에서는 지수와 반대로 버티거나 오르는 종목에 상대강도 보너스를 준다.
- 당일 주도 섹터와 그 안의 대장주를 먼저 찾는다.
- D0 장대양봉/상한가 종목은 D+1/D+2까지 추적한다.
- D+1/D+2 추적은 관찰 상태다. D+1 시가 추격매수를 의미하지 않는다.
- 강한 종목은 하루로 끝내지 않고 눌림/재돌파를 반복 관찰한다.

단타봇 지시:

```text
Leader Stock Gate

1. index_prediction보다 leading_sector / leading_stock 탐지를 우선한다.
2. KOSPI/KOSDAQ이 상승해도 상대강도 없는 종목은 후보에서 제외한다.
3. 지수 하락장에 양봉/상승/거래대금 유지 종목은 relative_strength_bonus를 준다.
4. D0 장대양봉/상한가 종목은 D+1/D+2 watchlist에 자동 기록한다. 단, D+1 시가 추격매수 신호로 해석하지 않는다.
5. D+3부터는 과열/차익실현 위험 구간으로 표시한다.
6. 대장주 지위가 유지되는 종목만 눌림/재돌파 반복 후보로 둔다.
```

필수 리포트 항목:

- 당일 주도 섹터
- 섹터 내 대장주/2등주/후발주
- D+1 성공/실패
- D+2 지속/꺾임
- 지수 하락 대비 상대강도
- 놓친 종목과 놓친 이유

적용 금지:

- "지수가 오른다"는 이유만으로 비주도주 매수
- 많이 빠졌다는 이유만으로 저가매수
- 대장주 확인 없이 후발주 추격

---

### C. 손절 영상 - 하락하는 날은 sell-only

참조 사례: 대한전선 D0/D+1 수익 후 D+2 손절. 살아 있는 날은 반복 매매, 죽은 날은 추가매수 금지.

단타봇에 필요한 부분:

- 오버나잇 종목이 다음날 상승하지 못하면 아침에 빠르게 위험 표시한다.
- 하락 중인 종목은 눌림이 아니라 실패일 수 있다.
- 하락하는 날에는 추가매수 금지, 보유분 정리 우선.
- `-3%`는 단순 가격 손절이 아니라, 그 손실을 감당 가능한 비중으로만 진입하라는 자금 원칙이다.
- 손절은 "더 빠질 것 같을 때"가 아니라 "오를 확신이 사라졌을 때" 한다.
- 평가손익/실현손익 복구 목적 매매를 금지한다.

단타봇 지시:

```text
Stop-Loss Discipline Gate

1. 오버나잇 D+1 종목이 시초 이후 상승 전환 실패 시 add_buy 금지.
2. D+2부터 거래대금 감소 + 음봉 + 대장주 지위 훼손이면 sell-only.
3. 최초 매수 근거가 훼손되면 물타기 금지, 정리 우선.
4. SAJANG.TRAILING_PCT=3.0 손실을 심리적으로 감당 가능한 비중만 진입한다.
5. "반드시 올라갈 근거"가 없으면 보유 사유 없음으로 표시한다.
6. 손익금액 복구 목적 매매를 차단한다. 판단 기준은 구조/수급/거래대금/주도성이다.
```

적용 금지:

- 떨어지는 종목 물타기
- 본전까지 기다리기
- 손실 복구를 위한 무리한 재진입
- D+2 이후 힘 빠진 종목을 D0/D+1처럼 공격

## 2. 단타봇 운영 우선순위

### 2.1 매수 후보보다 먼저 적용할 차단 조건

아래 중 하나라도 켜지면 매수 후보가 아니라 경고/관찰 후보로 낮춘다.

| 차단 항목 | 기준 | 단타봇 행동 |
|---|---|---|
| 하락 중 추가매수 | 보유 종목이 음봉/거래대금 감소/상승 전환 실패 | add_buy 금지 |
| D+2 힘 꺾임 | D+2에 음봉 + 거래대금 감소 + 대장주 지위 훼손 | sell-only |
| 이벤트 임박 | event_date-1 또는 event_date | 신규 진입 경고/금지 |
| 대장주 훼손 | 테마 대장이 먼저 급락/거래대금 이탈 | 후발주 추격 금지 |
| 손실복구 심리 | 손익금액 기준 재진입 | 차단 |

### 2.2 매수 후보로 올릴 조건

아래 조건이 많이 겹칠수록 상단 후보로 올린다.

| 가산 항목 | 의미 |
|---|---|
| D0 장대양봉/상한가 | 다음날 D+1 추적 대상 |
| 지수 하락 대비 상승/양봉 | 상대강도 강함 |
| 거래대금 유지/증가 | 돈이 계속 남아 있음 |
| 섹터 대장주 | 후발주보다 우선 |
| 이벤트 T+0~T+2 | 기대감 잔존 구간 |
| 눌림 후 재돌파 | 살아 있는 종목의 반복 매매 후보 |

## 3. 시스템 적용 단계

### Step 1. 리포트/라벨만 추가

자동매매 코드 변경 없이, 후보 리포트에 아래 라벨을 붙인다.

```text
leader_gate: PASS/WARN/FAIL
event_gate: EXPECTATION/OVERHEAT/D_DAY_RISK/NONE
stop_discipline: OK/ADD_BUY_FORBIDDEN/SELL_ONLY
d_day: D0/D+1/D+2/D+3+
relative_strength: STRONG/NEUTRAL/WEAK
external_shock_pullback: OBSERVE_ONLY/NONE
```

### Step 2. Shadow/Paper 검증

최소 5~10거래일 동안 아래를 측정한다.

- `leader_gate=PASS` 후보의 D+1/D+2 수익률
- `event_gate=D_DAY_RISK` 후보의 추격 손실률
- `external_shock_pullback=OBSERVE_ONLY` 후보의 양전환/휩쏘 비율
- `stop_discipline=SELL_ONLY` 후보를 계속 보유했을 때 손실 확대 여부
- 지수 하락장 상대강도 후보의 생존률
- D+3 이후 추격 후보의 손익비

### Step 3. Live 반영 조건

Live 반영 전 필수:

- 사장님 승인
- `SAJANG` 단일 진실 유지
- order path 변경 시 4-Tier 검수
- 보호매도/룰B/룰C/룰D 무손상
- No Intent No Order 유지
- 봇 OFF/freeze 상태에서 paper 먼저 확인

## 4. 의사결정 트리

```text
1. 오늘 주도 섹터/대장주인가?
   - 아니오 -> 후보 하단 또는 제외
   - 예 -> 2로 이동

2. D0/D+1/D+2 중 어디인가?
   - D0/D+1 -> 적극 관찰
   - D+2 -> 힘 유지 여부 확인
   - D+3+ -> 과열/차익 경계

3. 이벤트 일정이 있는가?
   - T+0~T+2 -> 기대감 구간
   - T+3 -> 추격 금지, 급락 반등은 관찰 라벨만
   - D-1/D-day -> 신규 진입 금지 경고

4. 지금 하락 중인가?
   - 예 -> 추가매수 금지, 보유분 정리 우선
   - 아니오 -> 5로 이동

5. 거래대금/수급/대장주 지위가 유지되는가?
   - 예 -> 눌림/재돌파 후보
   - 아니오 -> 관찰 하단 또는 sell-only
```

## 5. 단타봇 보고 문구 표준

### 매수 후보 상단

```text
[상단 후보] 종목명
- 근거: 주도섹터 대장 + D+1 + 지수 대비 상대강도 + 거래대금 유지
- 리스크: 이벤트 T+2, D+3 진입 시 추격 금지
- 행동: 눌림/재돌파만 관찰, 하락 전환 시 add_buy 금지. D+1 시가 추격 금지
```

### 경고 후보

```text
[경고] 종목명
- 이유: D+2 힘 꺾임 / 거래대금 감소 / 대장주 지위 훼손
- 행동: 신규매수 금지, 보유 시 sell-only 검토
```

### 이벤트 위험

```text
[이벤트 위험] 종목명
- event_date 임박: 기대감 소멸/차익실현 구간
- 행동: 신규 진입 금지, 보유분은 줄먹/트레일 우선
```

## 6. 금지 문장/금지 해석

- "지수가 불장이니까 아무거나 사도 된다" 금지
- "많이 빠졌으니 반등한다" 금지
- "손실이 커서 팔 수 없다" 금지
- "테마가 좋으니 이벤트 당일까지 들고 간다" 금지
- "D+2도 D+1처럼 공격한다" 금지
- "평가손익을 복구하려고 재진입한다" 금지
- "외부충격 눌림이면 자동 반등한다" 금지

## 7. 한 줄 지시

**단타봇은 매일 주도 섹터의 대장주를 D+1/D+2까지 추적하되, 이벤트 노출일과 하락 전환일에는 추격/물타기를 금지하고, 오를 근거가 사라진 종목은 손익이 아니라 구조 기준으로 정리한다.**

## 8. 6/8 검증 데이터 반영 주의

6/2 반등 전략 검증에서 엄격 walk-forward 기준 `rebound/pyramid`는 CLOSED 처리됐다.
따라서 본 문서의 "외부충격 눌림"은 매수 로직이 아니라 관찰 라벨이다.

- 급락 반등 자동매수 금지
- 양전환/거래대금 회복/대장주 지위 유지가 paper에서 확인되기 전 live 반영 금지
- D+1 추적은 watchlist 기록이며, D+1 시가 추격매수 금지
- 6/8~6/12 1차 paper 기준선 보존. 라벨 구현은 6/12 판정 이후 검토
