## §5. 자기성찰 템플릿 (매일 업무일지 마지막 섹션)

```markdown
## 자기성찰 (7/16 사장님 지시 — 매일 개선하는 단타봇)
1. **오늘 잘한 것**: (1~3개, 데이터/근거 포함)
2. **미흡·실수**: (숨기지 않기 — 정직이 자산. 없으면 "재점검했으나 발견 못함"이라 쓰고 내일 다시)
3. **새 교훈**: (영구 메모리 저장할 것인지 O/X 판정 포함)
4. **내일 적용 1가지**: (§4 각주에서 골라도 됨 — 구체적 행동 1개)
```

**운영 원칙**: 성찰은 반성문이 아니라 **개선 엔진**이다. ②에서 찾은 것이 다음날 ④가 되고, ④가 각주를 소진하고, 교훈이 메모리가 된다. 매일 1%씩.
