# 전략 데드라인 대장 (STRATEGY DEADLINES)

> **7/17 사장님 승인**: "전략에 데드라인을 겁니다 — 이게 진짜 진화다 → 진행하자."
> 원칙: **검증 → 판정 → 폐기/교체 사이클이 돌아야 엣지가 커진다.** 관측만 쌓고 판정하지 않는 전략 = 발전 없음.

## 운영 룰 (영구)

1. **데드라인 없는 전략은 등록 금지** — 신규 전략/관측은 시작일·정량 판정 기준·데드라인 3종 세트 없이 nightly에 배선할 수 없다.
2. **데드라인 도래 = 판정 보고 의무** — 단타봇이 데이터로 판정안(계속/폐기/교체)을 만들어 사장님께 보고. **폐기/교체/연장 결정은 사장님**(연장은 1회 원칙).
3. 판정 결과는 이 대장에 영구 기록(폐기된 전략의 사인도 자산).
4. 아침 루틴에서 D-3부터 카운트다운 확인(DAILY_ROUTINE A9).
5. 기존 불변식 유지: 관측 없이 flip 금지·라이브 전환은 언제나 사장님 결정.
