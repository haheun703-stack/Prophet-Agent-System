## 1. 두 시스템 현황

### 1-A. 상한가 엔진 (주력 — 메모리 ★★)
- **데이터**: `daily_limit_up_history` (Supabase, 6개월치) + `surge_patterns/*.json` (일별 급등)
- **시그널 (v3.0)**: 수급 등급 S/A/B + tipping_point + 섹터 로테이션 + 테마 동조 + 메가캡 동반
- **사전 조건**: 3회차+ 상한가 / 10일 누적 스마트머니 / 매도소진 < 0.7 / 거래량 압축 < 0.7
- **핵심 명제**: "약세장에서도 +10%/상한가는 매일 나온다 — 시장이 아니라 개별 종목 에너지에 베팅"
- **검증**: 5/19 D-Day KOSPI -5% 와중 바른손/졸스 +29.9% 상한가 동시 발생

### 1-B. 엘리어트 sweet (5/23 토 단타봇 발견)
- **데이터**: universe 200종 / 285 측정 / 5파 진입 58건
- **sweet spot**: 36~46% (중심 41%) 표본 9건 / 성공률 **55.6%** (x2.73 baseline)
- **trigger**: 4파 sweet 진입 + non_overlap → buy_signal (5파 폭발 기대)
- **시간 단위**: 일봉 (수일~수주 보유)

## 2. 결합 가능성 — 3가지 시나리오

### 시나리오 A: **강한 결합** (50%+ 일치)
> 상한가 친 종목의 절반 이상이 D-3~D-7일에 sweet 36-46% 4파 진입 후 5파 폭발 = 상한가

- **시너지**: sweet 진입 종목 자동 매수 → **상한가 사전 포지셔닝** (D-Day 직전 +X% 보유 후 상한가 잭팟)
- **구현**: enrich_with_elliott에 surge_likelihood 점수 추가, asset_pool 자동 매수
- **5/26 D-Day 적용**: 즉시 가능 (현재 enrich_with_elliott 통합 코드 존재)

### 시나리오 B: **부분 결합** (20~50% 일치)
> 일부 상한가 (정형 패턴 — 섹터 동조/연속 상한가 류)는 sweet 거치고, 일부 (갭상승/뉴스 단발)는 비정형

- **시너지 (부분)**: sweet 진입 시 surge 시그널 +N점 보너스 (조건부)
- **구현**: cross-validate 추가 (elliott sweet × surge candidate 매칭 시 +25점)
- **5/26 D-Day 적용**: 추가 2-3일 작업 필요

### 시나리오 C: **약한 결합** (<20% 일치)
> 상한가는 갭/뉴스/3파 돌파 위주 — 엘리어트 4파 정형 패턴과 무관. 사이클 시간축도 다름.

- **결정**: 두 시스템 **별개 운영** (현재 그대로)
  - 상한가 엔진 = limit_up_engine v3.0 (단기 1~3일 회전)
  - 엘리어트 sweet = asset_pool 보조 점수 (4파 진입 종목 한정)
- **이유**: 두 시스템 다른 시간축 / 다른 시그널 소스 / 결합 시 false positive 증가 위험

## 3. 검증 백테스트 제안 — `surge_elliott_correlation.py`

### 입력
- `daily_limit_up_history` 최근 1개월 (예상 100~300건)
- 각 상한가 D-Day 종목 ticker + date

### 처리
```
for each 상한가 종목:
    bars = KIS fetch_daily_chart (D-30 ~ D-1)
    elliott = detect_elliott_pattern(bars[:D-N])  # N=1,3,5,7,14
    record:
      - D-Day 직전 sweet 진입 여부 (36-46% zone)
      - D-Day 직전 4파 phase 여부
      - 진입 후 D-Day까지 일수
      - 사전 시그널 (수급 등급/섹터/테마)
      - 재상한가 사이클: 1차 상한가 후 N일 → 2차 상한가
```

### 출력 (통계)
| 지표 | 목표 | 결합 결정 |
|---|---|---|
| 상한가 종목 sweet 진입 비율 | >50% | 시나리오 A 강결합 |
| 상한가 종목 4파 phase 비율 | >30% | 시나리오 B 부분결합 |
| sweet 진입→상한가 평균 일수 | 3~7일 | 사전 포지셔닝 가능 |
| 재상한가 사이클 평균 | 5~15일 | 회전 매수 룰 도출 |
| 수급 S/A 등급 × sweet 동시 | ? | 최강 결합 룰 |

### 작업 시간 추정
- 코드 작성: 1시간
- KIS API 호출 (200건 × D-30 일봉): 2시간 (delay 0.3초)
- 결과 분석 + 보고서: 1시간
- **총 4시간** (사장님 시간 가능 시)
