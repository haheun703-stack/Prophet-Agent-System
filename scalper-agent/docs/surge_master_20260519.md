## 1. 시장 조건 카테고리

### 1-1. 강세장 (KOSPI +1%+, VIX <18)
- +10% 종목 = 50~150건/일
- 상한가 종목 = 5~15건/일
- 시그널 임계 **하향** OK (false positive 줄어듦)

### 1-2. 약세장 (KOSPI -1%+, VIX 20+)
- +10% 종목 = 20~60건/일 (오늘 5/19 추정)
- 상한가 종목 = 2~7건/일
- 시그널 임계 **상향** 필수 (시장이 끌어내리는 힘 강함)
- **테마성 종목만 살아남는다** (시장 무관한 호재 보유)
- **인버스 ETF +5%+** = 명확한 약세장 신호 (KODEX 인버스 5/19 +4.52%)

### 1-3. 횡보장
- +10% 종목 = 30~80건/일
- 가장 안정적인 환경

### 시장 판별 데이터 소스

- `data_store/regime_state.json` (브레인 시장상태)

## 2. 종목 사전 조건 (Pre-conditions)

### 2-1. **상한가 이력 패턴** (확률 ↑↑)
- **3회차+ 상한가**: 거의 100% 다음날 +시가 갭상승 (limit_up_engine 전략1)
- 직전 상한가 10일 이내
- 원점 대비 +300% 미만 (과열 필터)
- 최소 주가 1,000원 이상

### 2-2. **수급 사전 매집** (Tipping Point)
- 스마트머니(외인+기관+연기금+금투) **10일 누적 순매수**가 일평균 거래대금의 **0.5일치 이상**
- 매도 소진율 < 0.7 (개인 매도 70% 감소)
- 거래량 압축률 < 0.7 (조용한 축적)
- → `tipping_point_scanner.py` 핵심 로직

### 2-3. **섹터 로테이션 페이즈**
- EARLY/MID: 진입 유리 (감시기간 7일)
- LATE/REVERSAL: 진입 불리 (감시기간 3일 단축)
- STAGING: 다음 차례 (감시 OK)
- → `rotation_detector.py`

### 2-4. **테마 묶음 동조** (5/18 발견)
- 같은 섹터 5개+ 동시 급등 = 정책 이벤트 가능성
- 5/18 증권주 8개 +20~30% 일제 급등 — 거래소 이벤트
- 5/18 바이오 7개 +15~30% — 의약품 관련 호재
- **알고리즘 보강 필요**: 섹터 동조 카운터 (현재 미구현)

### 2-5. **메가캡 동반 급등**
- 시총 1조+ 대형주가 +15%+ 시 = 정책/구조적 호재 신호

## 3. 수급 시그널 카테고리 (6자 분석)

### 3-1. **수급 등급 (limit_up_engine v3.0 grading)**

| 등급 | 조건 | 의미 | 진입 |
|------|------|------|------|
| **S (강매집)** | smart_total > 0 + 연속 3일+ + 매도소진 < 0.7 | 스마트머니 강력 매집 | 🟢 최우선 |
| **A (매집중)** | smart_total > 0 + (연속 2일+ OR 외인+기관 쌍매수) | 매집 진행 | 🟢 우선 |
| **B (중립)** | smart_total ≥ 0 | 방향 불확실 | 🟡 조건부 (코일 시) |
| **C (이탈중)** | smart_total < 0 + 연속매수 없음 | 빠지는 중 | 🔴 차단 |
| **F (강이탈)** | smart_total < 0 + 매도소진 > 1.0 | 폭발적 이탈 | ⛔ 절대 차단 |

### 3-2. **수급 생존 필터** ⭐⭐⭐
> "급등 후 스마트머니가 빠졌으면 → 로테이션 때 안 돌아온다"

- **S/A 등급** → 생존 OK (즉시 통과)
- **B 등급** → 매도소진 < 0.8 AND 거래량압축 < 0.85 = 코일 상태 → 통과
- **C/F 등급** → 차단

### 3-3. **외인+기관 쌍매수** (Dual Buy)
- 외인 ≥ 2일 연속 + 기관 ≥ 2일 연속
- 한국시장에서 가장 강력한 매수 신호
- 다음날 평균 +3~5% 갭상승 (백테스트 결과)

### 3-4. **다자 합류** (Cross Confirmation)
- 6자(외인/기관/연기금/금투/개인/기타) 중 **4자+ 동시 매수**
- 매집 신호의 강력한 검증
- → `tipping_point_scanner.py` ④번 지표

### 3-5. **외인 OVERHEAT 차단** ⛔
- 동일 섹터에서 외인이 7일+ 연속 매수 후 첫 매도 전환
- → 5/18 -450만 사건의 원인 (메모리 [feedback_market_patterns_20260518.md])
- **무조건 차단 시그널**
- → `tools/flow_intelligence.detect_foreign_dump()` THEME_OVERHEAT

## 4. 기술적 시그널 카테고리

### 4-1. **STO (스토캐스틱) 패턴** (5/18 데이터 분석)
- **STO 상향 + STO 과매수 + 정배열**: 5/18 +10%+ 종목 30개 중 18개에서 발견 (60%)
- 단독으로는 약함 — 수급 시그널과 결합 시 강해짐

### 4-2. **거래량 패턴**

| 패턴 | 조건 | 의미 | 신뢰도 |
|------|------|------|--------|
| **대폭증** | vol_ratio ≥ 3x | 갑작스러운 관심 | ⭐⭐ |
| **저거래량 + 정배열 + MACD 양전환** | vol_ratio < 0.5 | 매물 소진 패턴 (대형주에 강력) | ⭐⭐⭐ |
| **거래량 압축 → 폭발** | 3일 압축 < 0.7 → 당일 5x+ | 코일 → 발사 | ⭐⭐⭐⭐ |

### 4-3. **MACD 양전환** + 정배열
- 단독 신뢰도는 보통
- 거래량 또는 수급과 결합 시 강해짐

### 4-4. **전일 양봉 + 거래량 증가**
- 연속 강세의 사전 신호
- 다음날 갭상승 확률 ↑

### 4-5. **VWAP 눌림 진입** ⭐⭐⭐⭐⭐ (HPSP 황금 패턴)
- 메모리 [project_4bot_collaboration]: 프로그램+ + 가격↑ + VWAP 눌림 모든 시그널 일치
- 현재 단타봇 라이브 사용 (5단계 게이트 ②번)

### 4-6. **상한가 마감 (close_strength ≥ 0.95)**
- 종가가 당일 최고가 근처
- 다음날 갭상승 가능성 매우 높음
