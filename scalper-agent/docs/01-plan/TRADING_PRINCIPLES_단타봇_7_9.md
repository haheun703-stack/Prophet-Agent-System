# 매매 원칙 적용 지시서 — 단타봇 (Prophet_Agent_System_예언자)

> 이 문서는 단타봇 프로젝트의 Claude 세션에 그대로 전달하는 **구현 지시서**다.
> 출처: ①김동엽(증권 34년차) 인터뷰 ②개인투자자 성공기(4회 실패 후 1천만→21억,
> 손익비·현금비중 체계) 두 영상에서 추출한 원칙 중 **단타 봇에 해당하는 것만** 담았다.
> 퀀트봇(quantum-master)용 원칙은 별도 문서에 있으며 여기 내용과 겹치지 않는다.

## 전제 (단타봇 Claude가 먼저 확인할 것)

이 문서는 단타봇의 코드베이스를 보지 않고 작성됐다. 따라서 아래 규칙을
적용하기 전에 반드시:

1. 기존 매매 파이프라인에서 **진입 결정 지점**과 **청산 결정 지점**을 특정하고,
2. 아래 각 규칙이 이미 구현돼 있는지 대조한 뒤 (있으면 파라미터만 비교),
3. 없는 것만 **관찰 모드 → 검증 → 활성화** 순서로 도입할 것.
4. 프로젝트 자체의 CLAUDE.md/아키텍처 규칙이 이 문서와 충돌하면 프로젝트 규칙이 우선.

## 규칙 1 — 손익비 사전 게이트 (최우선)

**원칙**: "매수 전에 손절가와 익절가가 먼저 있어야 한다. 손익비 1:4면
네 번 중 세 번 져도 본전이다." (성공기 영상의 핵심 안전핀)

**규칙 정의**: 모든 진입 주문은 주문 생성 시점에 다음 3값이 확정돼야 한다.

```
entry_price   : 진입가
stop_price    : 손절가  (예: entry × 0.97)
target_price  : 익절가  (예: entry × 1.06)
risk_reward   = (target - entry) / (entry - stop)
```

**게이트**: `risk_reward < RR_MIN` 이면 **주문 자체를 생성하지 않는다**.

| 파라미터 | 권장 기본값 | 비고 |
|---|---|---|
| RR_MIN | 2.0 | 영상 인물은 4.0 사용. 단타 특성상 2.0에서 시작해 데이터로 조정 |
| stop 산출 | 진입 로직의 무효화 지점 | 단순 % 고정보다 직전 지지/변동성(ATR) 기반 권장 |

**구현 지침**: 진입 시그널 생성부와 주문 실행부 사이에 독립 함수
`check_risk_reward(entry, stop, target) -> bool`로 삽입. 거부된 진입은
반드시 로그에 남길 것 (`RR_REJECT: 종목, rr=1.3 < 2.0`) — 이 로그가
나중에 "게이트가 수익을 깎았는지/살렸는지" 검증 데이터가 된다.

## 규칙 2 — 뇌동매매(추격 진입) 필터

**원칙**: "장중 급등을 보고 들어가면 마이너스 찍히고 대응이 안 된다.
수익은 5~10%씩 내면서 손실은 20~30%씩 맞는 구조가 깡통의 전형."

**규칙 정의**: 진입 시점에 아래 중 하나라도 해당하면 진입 금지(또는 감점):

```
a. 당일 등락률이 이미 +CHASE_MAX% 이상          (기본 +8%)
b. 최근 N분 상승 기울기가 급등 기준 초과          (기본 5분 +3%)
c. 현재가가 당일 고가 대비 -1% 이내 (고점 추격)   ← b와 조합 시만
```

| 파라미터 | 권장 기본값 |
|---|---|
| CHASE_MAX (당일 등락률 상한) | +8% |
| SPIKE_WINDOW / SPIKE_PCT | 5분 / +3% |

**주의**: 단타 전략 자체가 모멘텀 추종이라면 이 필터가 전략과 충돌할 수 있다.
그 경우 진입 금지 대신 **포지션 크기 절반 축소**로 완화 적용하고, 두 방식의
성과를 나눠 기록해 비교할 것.

## 규칙 3 — 일일 서킷브레이커 (손실 상한)

**원칙**: "아홉 번 이기고 한 번 잘못 치면 망하는 게 주식이다."

**규칙 정의**:

```
일일 누적 실현손실 ≥ DAILY_LOSS_LIMIT  → 당일 신규 진입 전면 중단
연속 손절 횟수    ≥ STREAK_LIMIT       → N분 쿨다운 (연타 방지)
```

| 파라미터 | 권장 기본값 |
|---|---|
| DAILY_LOSS_LIMIT | 계좌의 -2% (페이퍼면 가상 원금 기준) |
| STREAK_LIMIT / 쿨다운 | 3연속 손절 / 60분 |

**구현 지침**: 장 시작 시 리셋되는 일일 상태(state)로 관리. 발동 시
텔레그램/로그로 명확히 알릴 것 (`CIRCUIT_BREAKER: 일일한도 도달, 신규진입 중단`).

## 규칙 4 — 공통 원칙 2건 (퀀트봇과 공유)

**4a. 마이너스 먼저 잘라라**: 포지션 축소가 필요할 때 수익 종목이 아니라
**손실 확대 중인 종목부터** 정리한다. 손절 주문이 걸려 있어도 "손절가를
아래로 옮기는 행위(물타기성 버티기)"를 금지하는 코드 레벨 가드 권장.

**4b. 테마는 한 때다**: 특정 테마/섹터 소속 종목의 연속 손절이 누적되면
(예: 동일 섹터 3회) 해당 섹터를 쿨다운 리스트에 넣고 당일~익일 진입 제외.

## 롤아웃 순서 (반드시 이 순서로)

1. **관찰 모드 (1~2주)**: 규칙 1~3을 실제 차단 없이 "발동됐을 것" 로그만 기록.
   기존 페이퍼 매매와 병행 → 각 규칙이 막았을 손실 / 놓쳤을 수익 정량화.
2. **백테스트 (가능하면)**: 기존 체결 이력이 있다면 규칙 1·3은 과거 데이터로
   즉시 검증 가능. "RR_MIN 2.0을 적용했다면 총손익이 어떻게 변했나"를 계산.
3. **활성화**: 관찰/백테스트에서 개선이 확인된 규칙만 실제 차단으로 전환.
   한 번에 하나씩 켜고 1주 간격을 둘 것 (효과 분리).

## 검증 기준 (활성화 판단)

- 규칙 1: RR 게이트 적용 시뮬레이션 총손익 ≥ 미적용 총손익, 且 MDD 감소
- 규칙 2: 필터에 걸린 진입들의 평균 수익률이 실제로 음수였는지 확인
- 규칙 3: 서킷브레이커 발동일의 "발동 이후 가상 체결" 평균이 음수였는지 확인
- 판단 표본: 규칙당 최소 20회 발동 사례

## 금지 사항

- 이 문서의 파라미터를 "정답"으로 취급하지 말 것 — 전부 시작값이며 데이터로 조정
- 관찰 검증 없이 실매매(실계좌) 로직에 바로 붙이지 말 것
- 기존 봇의 리스크 규칙을 이 문서 기준으로 **약화**시키지 말 것
  (기존 규칙이 더 보수적이면 기존 유지)
