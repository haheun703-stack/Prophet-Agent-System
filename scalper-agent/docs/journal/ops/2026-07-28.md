   - 페이퍼에서 강도≥400이 **+12.03%p 플러스**로 뒤집혔을 때 흥분하지 않고 백테스트로 즉시 교차검증 → **−57.53%p로 기각**. 7/27 교훈("단일 유리 결과에 성급히 흥분")을 하루 만에 실제로 적용
   - 유일한 플러스 후보(추격<5.5)를 **스스로 3중 검증해서 기각**. 좋은 결과를 지키려 하지 않았음
   - 커버리지 72.5%(전체 파일)를 그대로 보고했으면 오탐이 될 뻔한 것을 활성 기준으로 재계산

2. **미흡·실수**
   - **7/27 F-24 "체결강도 역상관"을 메모리에 확정적으로 기록했는데 하루 만에 기각됐다.** 당시 페이퍼 41건 표본·순위정렬 한 가지 연산만 보고 "역상관"이라는 **일반 법칙 형태로 적은 것**이 과했다. 백테스트 교차검증을 그때 같이 했어야 했다
   - on_fail 교체후보 중 명분 게이트가 **실행 불가**라는 걸 D-3에야 발견. 7/17 등재 시점에 확인했어야 함(→ F-25 등재)
