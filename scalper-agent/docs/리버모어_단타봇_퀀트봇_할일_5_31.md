# 제시 리버모어 → 단타봇·퀀트봇 할 일 (5/31, 통합 이론)

> 사장님 5/31: 리버모어 전략을 읽으면 단타봇·퀀트봇 할 일이 명확해진다.
> ★ 리버모어 = 우리가 주말에 데이터로 검증한 모든 것의 통합 이론. 그리고 놓친 1조각(피라미딩 사이징)을 채움.
> 단타봇 도메인이지만 퀀트봇 섹션 포함 → 사장님이 퀀트봇에 전달.

## 0. 핵심 — 리버모어가 우리 주말 발견과 정확히 겹친다
| 리버모어 원칙 | 우리가 데이터로 검증/구현한 것 |
|---|---|
| 단타는 비중 못 실어 큰돈 못 범 → 추세추종 전환 | rolling-ride 거래당 +7.42% > D+3, 단 자본효율 트레이드오프 = **피라미딩이 답** |
| 정보 시차 + 세력 분할매집 = 추세 시작 | 정보봇 event_signals(재료 시차) + 수급 트래커(외인/기관) + 점화 |
| 추세판별 4기준(price+volume, 지표 없이) | 점화 족적 추출(기지 돌파+거래량) + score_kki |
| 승률 무관, 손익비(질때 작게 이길때 크게) | STOP_REENTER 승률 39~73% but 손절+재진입 > 견디기 +5~6%p |
| 횡보=휩소=관망 | 명분게이트(약신호 더미 거름) + regime |
| 피라미딩(불타기 ≠ 물타기) + 변동성별 손절폭 | ★ 우리가 놓친 조각 — 재진입의 진짜 형태 ★ |
| 심리 봉인(손절 박제, 누적손실 중단) | SAJANG 단일진실 + AUTO_TRADE_DISABLED |

## 1. 리버모어 추세판별 4기준 → 단타봇 점화 무기 (정교화 사양)
점화 스캐너(ignition_footprint)를 리버모어 4기준으로 다듬는다:
1. **전환점(지지/저항)**: 저점 높임(HL) + 직전 고점 돌파(HH) = 상승추세 시작. (현 점화 정의에 HH/HL 구조 추가)
2. **최초 저항선 돌파**: 박스권 상단을 **거대 거래량과 함께** 돌파 = 점화 확증. (현 "기지 위치≤60% + 거래량2.5x" 기준 = 이거. 박스권 압축→분출)
3. **가격-거래량 조화**: 상승=거래량↑ / 조정=거래량↓ + **조정은 직전 상승의 절반 이내 + 며칠 = 눌림목(매수자리)**. 신고가인데 거래량↓ = 다이버전스(위험).
4. **위험신호(청산)**: ①폭발적 거래량 오버슈팅 후 음봉/긴 윗꼬리(장대 피뢰침=세력 덤핑) ②거래량 다이버전스. → 전량청산.
→ 점화 7미검출 문제(나무기술 등)는 **②박스권 돌파 + ①HH/HL 구조**로 재정의하면 잡힘. 백테스트로 검증.

## 2. 피라미딩 = 재진입 룰의 진짜 형태 (재설계) ★ 우리가 놓친 핵심 ★
우리 STOP_REENTER는 원시 버전. 리버모어 **피라미딩(불타기)**이 완성형:
- **역피라미드 분할 진입**: 최초 10% 정찰 → +20% 수익 확인(판단 적중) → +20% 추가 → 계속 상승 → +30% → 후반 +40% = 100%. **후반에 더 크게**(추세 후반이 가장 가파른 급등).
- **물타기 절대 금지**(내려갈 때 추매 = 계좌 파멸). 오직 **오를 때만** 비중↑.
- **손절(사이징과 쌍)**: 10%만 든 상태 -10% → 즉시 손절 = 전체 자산 **1%**. 30% 든 상태 추가매수가 -10% → 전량청산 = 전체 **2~3%**.

★★★ **−4.5% vs −3% 논쟁 재해석 (우리 shakeout study의 빈틈)** ★★★
- 우리 분석은 **풀 포지션 가정** → "고변동 -3% 넓히면 손해" 결론.
- 리버모어: **고변동 잡주 = 손절폭 40%+ 넓게, 단 초기 사이즈 10% 정찰.** 우량주 = 촘촘하게.
- → **넓은 손절 × 작은 초기비중 = 나무기술 흔들기(-6.6%) 버티면서 계좌 리스크 1%.** 우리가 "넓히면 손해"라 한 건 사이징을 안 묶어서다.
- ⇒ **재검증 필요**: 피라미드 사이징(10%정찰+불타기) 넣은 점화 백테스트 → -3% 결론이 바뀌나.

## 3. 손익비 시스템 = STOP_REENTER 검증과 일치
- 승률 20~25%여도 OK(질때 -1% 작게, 이길때 추세 끝까지 크게). 우리 데이터: 손절+재진입 > 견디기.
- **백테스트 지표 = 승률 X, 손익비/기대값 O.** 단타봇·퀀트봇 둘 다 이 지표로 평가.

## 4. 횡보 관망 = 명분게이트 + regime
- 횡보장 = 가짜돌파 휩소 = 승률 낮은 근본원인. 방향 못 잡으면 **관망**.
- 우리 명분게이트(재료·수급·기술위치 강≥2)가 약신호 더미(횡보 가짜돌파) 거름 = 리버모어 "관망"의 코드화.

## 5. 심리/리스크 봉인 (4번 파산 교훈) → SAJANG에 박기
- 누적 손실 **30% 도달 → 즉시 매매 중단**(1주~1달). → SAJANG 신규룰 후보.
- 복귀 시 **가용자산 50%로** 시작(심리 회복). → SAJANG 신규룰 후보.
- **손절 가격을 숫자로 박아두기** = 유일한 심리 봉인. → 이미 SAJANG.get_normal_sl/trailing.
- **타인 정보/조언에 흔들리지 마라**(퍼시 토마스 사건 = 최대 파산). → 정보봇 event_signals도 "입력일 뿐, 단타봇 자체 selector가 결정"(5중 가드와 정합).
- 연승 후 자만 = 1번 원칙 위반 = 파멸. → "이 정도면 됐다 판단 금지"(CLAUDE.md) + SAJANG 단일진실.

## 🟦 단타봇 할 일 (구체)
1. **점화 스캐너를 리버모어 4기준으로 정교화** (HH/HL 전환점 + 박스권 거래량 돌파 + 조정 절반/거래량 + 위험신호). → 7미검출 해결.
2. **재진입 = 피라미딩으로 재설계** (10% 정찰 → 불타기 20/30/40%, 물타기 금지, 변동성별 손절폭+사이징). reentry_rule_5_31.md 갱신.
3. ★ **−3% 결론 재검증** — 피라미드 사이징 넣은 점화 백테스트(고변동=넓은손절×작은비중).
4. 명분게이트(횡보 거름) + 심리 봉인 SAJANG 신규룰(누적30%중단/복귀50%).
5. 정보봇 event_signals = 정보시차/세력매집 감지 입력(명분), 결정은 단타봇 selector.

## 🟩 퀀트봇 할 일 (구체 — 사장님 전달)
1. **알파를 추세추종으로** — supply D20(평균회귀성) 가짜였음. 리버모어/현대 알고 90% = **오르는 거 더 사고 떨어지는 거 판다**(추세추종). 퀀트 알파를 이 방향으로.
2. **손익비/기대값 지표** (승률 아님) — 백테스트 평가축 전환.
3. **횡보 회피** — SHIELD/regime으로 횡보장 매매 중단(휩소 방어).
4. **세력 분할매집 조기 감지** — 수급 D20·nationality flow를 "기관 분할매집=추세시작" 관점으로 재해석(정보 시차 활용).
5. **공매도 양방향** — 리버모어는 폭락장 공매도로 거부. BRAIN 인버스/레버리지 ARM = 하락추세도 먹는 추세추종(이미 개념 있음, 강화).
6. **피라미딩 사이징** — 확신 검증될 때만 비중↑(역피라미드), 자금배분에 적용.

## ⚠️ 정직
- 리버모어 = 강력한 통합 이론이나, **여전히 백테스트로 검증해야 함**(생존편향·휩소·비용). 그가 4번 파산한 건 천재도 원칙 어기면 죽는다는 증거 = 우리 검증·봉인 규율의 정당화.
- 가장 중요한 재검증 = **피라미딩 사이징 넣은 점화+재진입 백테스트** (−3% 결론 + 자본효율 재평가).
