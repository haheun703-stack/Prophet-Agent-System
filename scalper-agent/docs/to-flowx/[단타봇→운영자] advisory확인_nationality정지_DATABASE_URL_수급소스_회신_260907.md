## 2. `nationality_flows` 재탕 — 소유 확인 + 정지 완료

### 2-1. 소유: **단타봇 맞습니다** (코드 실측)

퀀트봇이 지목한 4곳 전부 저희 코드에 실재합니다.

| 위치 | 내용 |
|---|---|
| `data/upload_short.py:3` | `"""담당 테이블: short_signals, nationality_flows"""` |
| `data/upload_short.py:374` | `def upload_nationality_flows()` — `client.table("nationality_flows").upsert(...)` |
| `bot/trading_coo.py:2453` | C25 「국적 X-ray」 잡이 매일 호출 |
| `bot/trading_coo.py:4078-4081 · 4299-4306` | AUTO-RECOVERY `nationality_xray` + `_recover_nationality_flows()` |

**재탕 메커니즘도 확정했습니다** — `upload_short.py`가 행을 만들 때 날짜를 이렇게 찍습니다:

```python
today_str = str(date.today())      # ← 행의 date = 오늘
...
rows.append({"date": today_str, ..., "countries": {"date_new": <CSV 최신일>, ...}})
```

즉 **`date`는 오늘인데 `countries.date_new`는 원천 CSV 날짜**입니다. 원천이 멈춰도 행은 매일 새로 찍힙니다.
저희 VPS 마커 실측: `{"date": "2026-09-06", "count": 1911, ...}` — 정보봇 관측치와 일치합니다.

### 2-2. 규모 (지시 §2-4 "먼저 멈추고 규모 보고")

Supabase 읽기 전용 집계(9/7):

| 구간 | 행수 | 비중 |
|---|---|---|
| 전체 | **273,224** | 100% |
| 6/22 이후 (KRX 차단 이후 = 재탕 구간) | **147,147** | **53.9%** |

전 종목 통틀어 **가장 신선한 원천이 6/19**이고, 그것도 80일 전입니다.

### 2-3. 조치 — 신선도 가드 (당일 구현·테스트 23건)

`data/upload_short.py`에 원천 신선도 판정을 넣고, **낡으면 업로드 자체를 스킵**합니다.

```python
NATIONALITY_STALE_MAX_DAYS = 4          # 지시서 권고값

stale, latest_src, age = _nationality_source_age(all_codes)
if stale:
    logger.warning("[FLOWX] nationality_flows 원천 stale(최신 %s · 경과 %s일 > %d일) → 업로드 스킵 ...")
    _write_nationality_marker(0, 0, 0, skipped=True, reason=f"source_stale:{latest_src}:{age}d")
    return False
```

설계에서 신경 쓴 4가지:

1. **AUTO-RECOVERY 우회 통로 0** (지시 §2-3) — 복구 경로 `_recover_nationality_flows()`가 **같은 함수를 호출**하므로
   가드를 한 곳에 두면 양쪽에 적용됩니다. 복구용 가드를 따로 만들지 않았습니다(두 벌은 갈라집니다).
   테스트로 *"복구 경로에 별도 upsert가 없다"* 를 고정했습니다.
2. **무한 재시도 방지** — 스킵해도 마커에 오늘 날짜를 남깁니다. 안 남기면 AUTO-RECOVERY가 매 사이클 재시도합니다.
   대신 `skipped: true` · `reason: "source_stale:20260619:80d"` · `count: 0`을 함께 적어
   **마커만 보고 '업로드됨'으로 오독할 수 없게** 했습니다(성공 위장 차단).
3. **판독 불가는 stale로 접습니다** — 원천 목록이 비었거나 날짜 형식이 깨지면 발행하지 않습니다. *모르면 안 내보낸다.*
4. **정상 경로 회귀** — 원천이 신선하면 종전대로 끝까지 업로드합니다(테스트에서 upsert 호출 확인).

검증: 신규 테스트 **23건 PASS**(경계 4일=통과/5일=stale · 음성대조: 가드 없던 동작은 6/19도 통과) · 전체 회귀 **54/54** ·
pre-commit ✓ · Codex ✓ · VPS 실측.

★ **오늘 밤 C25부터 스킵됩니다.** 표는 더 이상 늘지 않고, 대신 **결손이 눈에 보이게** 됩니다 — 퀀트봇 8/11 조치와 같은 방향입니다.

## 4. 외인 국적별 수급 소스 재연결 — **불가 (사장님 영구 룰)**

- 사장님 6/22 확정 영구 룰: **KRX 일절 미접근** — nationality(국적별) 포함. 원인은 KRX 계정잠금(CD007)이었고,

- 지시서 §4-1이 물으신 *"먼저 그 소스가 살아 있는지"* — **살아 있지 않습니다.** §2에서 보신 대로 저희 원천도 6/19에 멈춰 있고,
